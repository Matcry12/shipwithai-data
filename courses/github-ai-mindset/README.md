# Ship with AI — The Junior Developer's Edge in 2026

**Audience:** students, bootcamp grads, career-changers, non-developers, and junior devs entering tech in the 2026 AI-native hiring reality.
**Format:** 10 modules in 2 acts + a bridge — short lessons, a "Who this is for" note, and one hands-on Action per module.
**Through-line:** *AI writes the code now. Your job is to out-judge it — and GitHub is where you prove you can.*

> The three things AI can't do for you, and that this course is built around: **judgment** (knowing if the output is right), **ownership** (standing behind it), and **communication** (explaining why). Every module's claims are grounded in the `cv-rag` corpus (`topic = github-ai-vibe`) and cited inline by source domain, with a Sources Cited list per module.

The modules live in this directory, one file each. The full design rationale and the mapping from the earlier version of this course is in [`COURSE-OUTLINE.md`](COURSE-OUTLINE.md).

## How the course is structured

It delivers in **3 phases**, mapped to the arc:

- **Phase 1 = Act 1 (Modules 1–6)** — become the judge. Why the bar moved, the understanding you need, learning without atrophy, the toolset, vibe coding safely, and the verification skill that ties it together.
- **Phase 2 = Bridge (Module 7)** — the real AI-on-GitHub loop, where judging code becomes working the way teams work.
- **Phase 3 = Act 2 (Modules 8–10)** — prove it and get hired: the evidence locker, a flagship build, and landing the role.

## Suggested learning path

Linear, **1 → 10**. Act 1 builds the judgment; the Bridge puts it on GitHub; Act 2 turns it into proof and an offer. Module 6 is the hinge — if you read only one, read that one. Module 9 assumes you've done Act 1.

## Design principles

- **Accessible to non-developers.** Every lesson is pitched for non-devs; deeper CS material is quarantined in optional *"developer track"* notes.
- **Vendor-neutral.** Tools (Copilot, Cursor, Claude Code, Lovable, Bolt, Replit, …) appear only as *examples* of durable categories, never as the spine.
- **Freshness-disciplined.** Volatile figures (prices, salaries, benchmarks, specific tools) live in clearly-dated callouts; the body teaches what won't rot.
- **Grounded & cited.** Every substantive claim is drawn from the `cv-rag` knowledge base (`topic = github-ai-vibe`) and cited inline as `*(domain)*`.
