# Karshil Sheth - Resume Repository 📋
> A comprehensive collection of professional resumes tailored for different experience levels and job opportunities, complete with LaTeX source files and cover letters.

## 📁 Repository Structure

```
Karshil_Sheth_Resumes/
├── Resume1.0/          # Entry-level resumes (1.0-1.5 years)
├── Resume2.0/          # Mid-level resumes (1.5-3.0 years)
├── Resume3.0/          # Senior-level resumes (3.0+ years)
├── Resume5.0/          # Latest resume versions
├── CoverLetters/       # Professional cover letters
└── LatexSourceCode/    # LaTeX source files for customization

```

## 🎯 What's Inside
### Resume Files
  * **Multiple Formats** : PDF versions optimized for ATS systems
  * **Role-Specific** : Tailored for Java Developer, Full-stack Developer, etc.
  * **Industry-Optimized** : Customized for different sectors


### Cover Letters
  * Professional templates (PDF & DOC formats)
  * Customizable for specific opportunities


### LaTeX Source Code
  * Full source files for easy editing
  * Version-controlled templates
  * Professional formatting presets


## 🛠️ How to Customize
  1. Navigate to `LatexSourceCode/`
  2. Open the `.tex` file for your target version
  3. Edit content as needed
  4. Compile with LaTeX (TeXworks, Overleaf, etc.)
  5. Export to PDF
