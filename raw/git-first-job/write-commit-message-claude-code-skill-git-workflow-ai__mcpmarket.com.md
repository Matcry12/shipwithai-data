# Write Commit Message

Generates standardized, professional git commit messages following Conventional Commits guidelines and best practices.

This skill enforces a clean and consistent version control history by guiding Claude to write commit messages using the industry-standard Conventional Commits specification. It automatically handles various commit types—such as features, fixes, and refactors—while ensuring appropriate formatting, imperative mood, and the exclusion of unnecessary AI attribution footers. Designed to integrate seamlessly with Spec-Test-Driven Development (STDD) workflows, it helps maintain a machine-parsable git history that is ideal for automated changelog generation and team collaboration.

## Key Features

01Enforces Conventional Commits 1.0.0 formatting for all git messages

02Suppresses AI-generated watermarks to maintain a clean, human-centric commit log

03Optimizes for readability with 72-character limits and imperative mood

04Handles breaking change notation with exclamation marks and footer documentation

05Supports specialized commit types including feat, fix, docs, refactor, and ci

01Standardizing commit practices across a multi-developer team to improve code review efficiency

02Automating standardized commit messages during a Spec-Test-Driven Development (STDD) cycle
