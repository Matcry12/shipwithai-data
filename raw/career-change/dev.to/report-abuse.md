# Report abuse
Thank you for reporting any abuse that violates our [Code of Conduct](https://dev.to/code-of-conduct) and/or [Terms and Conditions](https://dev.to/terms). We continue to try to make this environment a great one for everybody. If you are submitting a bug report, please [create a GitHub issue](https://github.com/forem/forem/issues/new?assignees=&labels=bug&projects=&template=bug_report.md&title=) in the main Forem repo.
