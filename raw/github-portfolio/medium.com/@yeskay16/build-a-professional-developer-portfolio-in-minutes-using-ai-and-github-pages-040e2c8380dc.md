### Step 2: Prepare the Portfolio for Hosting

Once the portfolio code is ready, you simply need a basic structure like:

```
index.html
style.css
assets/
```

This minimal structure is perfect for hosting on **GitHub Pages**.

GitHub Pages allows you to host static websites **completely free**, making it ideal for portfolios.

### Step 3: Deploy the Portfolio Using GitHub Pages

To deploy your website:

1. Create a new repository on GitHub- Upload your portfolio files- Go to **Repository Settings → Pages**- Select the **main branch** as the source- Save the configuration

Within a few seconds, your portfolio will be live at:

```
https://username.github.io/repository-name
```

No servers, no hosting cost, and no complex setup.
