**Link of my profile:[My GitHub Profile](https://github.com/farrahdlsdionisio)**
I am currently looking for a new organization to join. While doing so, I decided to build a stronger online presence as a software engineer. The first thing I'm going to improve is my GitHub profile. I drafted a plan in my notebook that includes six sections: a header, a quick introduction, a list of technologies I've used, GitHub stats, links to my social media accounts, and my resume for potential employers who will visit my profile.
The first section is the header, which I designed to be simple yet eye-catching using Figma.
[![personal brand created using figma](https://media2.dev.to/cdn-cgi/image/width=800%2Cheight=%2Cfit=scale-down%2Cgravity=auto%2Cformat=auto/https%3A%2F%2Fdev-to-uploads.s3.amazonaws.com%2Fuploads%2Farticles%2Fhyibbmc7fjqom9cb5tx3.png)](https://media2.dev.to/cdn-cgi/image/width=800%2Cheight=%2Cfit=scale-down%2Cgravity=auto%2Cformat=auto/https%3A%2F%2Fdev-to-uploads.s3.amazonaws.com%2Fuploads%2Farticles%2Fhyibbmc7fjqom9cb5tx3.png)
After that, I researched some fun widgets to add to my profile. I found the profile views badges by Anton Komarev: [GitHub Profile Views Counter](https://github.com/antonkomarev/github-profile-views-counter?tab=readme-ov-file)
To apply it add this to your readme.md (change it to your username)  


```
![](https://komarev.com/ghpvc/?username=yourusername&color=FF7A8A&style=for-the-badge)

```

I love listening to music while working, as I was searching for a cool GitHub profile I stumbled upon a widget where you can show what's currently playing on your Spotify so I decided to use it as well. I got it from here: [Spotify GitHub Profile](https://github.com/kittinan/spotify-github-profile)
To apply it to your readme.md, go to the link that I provided, connect your Spotify and grant permission
[![Connect spotify with github](https://media2.dev.to/cdn-cgi/image/width=800%2Cheight=%2Cfit=scale-down%2Cgravity=auto%2Cformat=auto/https%3A%2F%2Fdev-to-uploads.s3.amazonaws.com%2Fuploads%2Farticles%2Fvqrpc2clcc887us0zvvh.png)](https://media2.dev.to/cdn-cgi/image/width=800%2Cheight=%2Cfit=scale-down%2Cgravity=auto%2Cformat=auto/https%3A%2F%2Fdev-to-uploads.s3.amazonaws.com%2Fuploads%2Farticles%2Fvqrpc2clcc887us0zvvh.png)
You'll be redirected to where you can choose your theme, change the color of the player, etc. Click copy to clipboard and apply it to your readme.md 
[![Spotify GitHub Profile](https://media2.dev.to/cdn-cgi/image/width=800%2Cheight=%2Cfit=scale-down%2Cgravity=auto%2Cformat=auto/https%3A%2F%2Fdev-to-uploads.s3.amazonaws.com%2Fuploads%2Farticles%2Fngxzue17u2uiesn711we.png)](https://media2.dev.to/cdn-cgi/image/width=800%2Cheight=%2Cfit=scale-down%2Cgravity=auto%2Cformat=auto/https%3A%2F%2Fdev-to-uploads.s3.amazonaws.com%2Fuploads%2Farticles%2Fngxzue17u2uiesn711we.png)

The next section displays my GitHub data. I found this widget from Anurag Hazra that pulls your total stars earned, total commits(current year), total PRs, total issues, and contributed to(last year). You can check it here: [Github Stats](https://github-readme-stats.vercel.app/) Go check the documentation as it offers a lot of customization for your needs. For me, I just used the default view and changed the theme. 
To apply it to your readme you can do it as follows (change it to your username):  


```
<p align="center"> <img src="https://github-readme-stats.vercel.app/api?username=yourusername&theme=prussian&show_icons=true" alt="yourusername" /></p>

```
