### GitHub Portfolios Workshop
Welcome to GitHub Portfolios, a workshop hosted by UO Libraries [Data Services](https://library.uoregon.edu/data-services) and the [UO Career Center.](https://career.uoregon.edu/)
**To participate, please create or sign into your free GitHub account at[github.com.](https://github.com/)** You'll need an email address and we strongly recommend that you set up some sort of two-factor authentication device (such as the Duo app on your phone that you may use to sign in to Duckweb). [Here's detailed instructions](https://docs.github.com/en/get-started/start-your-journey/creating-an-account-on-github).
GitHub is a cloud-based platform where [you can store, share, and work together with others to write code](https://docs.github.com/en/get-started/start-your-journey/about-github-and-git). It's also a great place to showcase your work to potential employers and collaborators. These [instructions from GitHub summarize what we'll over today](https://docs.github.com/en/account-and-profile/setting-up-and-managing-your-github-profile/customizing-your-profile/using-your-github-profile-to-enhance-your-resume).
#### What makes a good GitHub portfolio?
A simple, professional GitHub portfolio has:
  * a professional photograph or icon
  * your name
  * links to LinkedIn profile, professional website, ORCiD or other professional web presence
  * a special repository that has the name of your GitHub username 
    * this creates a special repository where you can create a README.md page that will show up on the front page of your GitHub
    * put in this README a very short introduction and summary of relevant job experience
  * add pinned repositories showcasing your coding skills


You can add bells and whistles, but don't need to! Only add things like "GitHub stats" if they make you look good.

#### Step by Step Instructions
  1. Brainstorm and draft your "about me."
  2. Create[github.com.](https://github.com/)
  3. Personalize your GitHub main page by adding information about who you are, a headshot or avatar, and a link to your LinkedIn.
  4. Create a profile repository and put your About Me text in it. See [the first few instructions here](https://medium.com/design-bootcamp/how-to-design-an-attractive-github-profile-readme-3618d6c53783). Or [read GitHub's documentation here](https://docs.github.com/en/account-and-profile/setting-up-and-managing-your-github-profile/customizing-your-profile/managing-your-profile-readme). Here's [a list of badges](https://github.com/inttter/md-badges) you can add to your About me.
  5. Make sure your code repositories are documented with a README that explains what it is and how to use it. Ideally, also specify an environment in which to run the code using an environment file.
