# Using GitHub as a Portfolio When Applying for Jobs · community · Discussion #169760

Original comment in English -

## Select Topic AreaQuestion ## BodyI'm curious how other developers here use GitHub when applying for jobs. Some companies check your GitHub profile before or after interviews, so I'm wondering: What kind of projects do you keep public for employers to see? Do you write detailed READMEs to explain your work? How much do recruiters actually value GitHub contributions compared to a traditional resume? |

Beta Was this translation helpful? Give feedback.

I try to put effort into writing good README files — I treat them almost like a portfolio write-up. I include:

- What the project is
- What tools/technologies were used
- Setup instructions
- Screenshots or demo links
- A brief explanation of what I learned or solved

As for how much GitHub matters compared to a resume:

It really depends on the company. Tech-first or open source-friendly companies often take GitHub seriously — sometimes more than a resume. But for more traditional companies, it's just a bonus.

Either way, a well-curated GitHub profile can absolutely help you stand out and back up your skills with real work.
